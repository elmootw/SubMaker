# SubMaker

給一支影片，自動產生 Final Cut Pro 用的字幕檔（`.fcpxml`）的 Mac 應用程式。

## 目的

把影片丟進 SubMaker：自動聽寫字幕、轉成台灣繁體並整理好，產出 `.fcpxml`。
匯入 Final Cut Pro 後，全選字幕貼到正式剪輯時間軸的最開頭，在 FCP 裡邊剪邊改。

SubMaker 不剪影片，也不在 App 裡逐條編輯字幕。

## 使用流程

1. 打開 SubMaker，把影片拖進視窗
2. 選填：這支影片的專有名詞（幫助聽寫）、調整字幕樣式（有預覽）
3. 按「開始」：聽寫 → 轉繁體 → 取代規則 → 自動整理
4. 選填：搜尋、全部取代
5. 按「產出」：影片旁邊產生同名 `.fcpxml`，匯入 FCP

影片旁邊有同名 `.srt` 時，改用那份 srt，不聽寫。
